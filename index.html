Dengue (DBD) case forecasting for Indonesia

Team project, Kelompok 4 DSGA

A dashboard that forecasts dengue cases for each province using 2020–2025 data. Each province gets the model that performed best for it, and the page shows trends, climate and sanitation factors, a risk map and what-if simulations.

  • 34 provinces, each matched to its best model: Random Forest, XGBoost or Prophet
  • Five data tables served from a Supabase (PostgreSQL) database
  • Interactive Streamlit app with six pages, deployed on Streamlit Community Cloud
